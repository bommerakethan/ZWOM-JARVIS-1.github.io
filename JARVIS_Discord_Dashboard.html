Deployment checklist

  1. Deploy backend on Render.
    Use the backend/ folder in this same GitHub repository.
  2. Set secret environment variables.
    Configure Discord public key, application ID, bot token and AI provider key in Render. Never commit secrets.
  3. Register the slash command.
    Run python register_command.py locally with the required environment values.
  4. Configure Discord.
    Paste the exact endpoint URL shown here into Developer Portal → General Information → Interactions Endpoint URL.
  5. Verify.
    Discord sends a signed PING. The backend validates the signature and returns {"type":1}.
